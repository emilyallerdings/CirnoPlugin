# CirnoPlugin
Adds cirno fumo to CloverPit using CustomPowerupAPI


## Requirements

- [BepInEx](https://github.com/BepInEx/BepInEx)
- [CustomCharmAPI](https://github.com/emilyallerdings/CustomCharmAPI)

## Installation

1. Install BepInEx if you don't have it already.
2. Install CustomCharmAPI if you don't have it already.
3. Extract the contents of the `.zip` file into the `BepInEx/plugins` folder.
4. Launch the game — the plugin will load automatically.

## Usage

No additional setup is required. The plugin will run on game launch.
